## Target

- [ ] T1: 查明截图中文档链接点击后无法打开目标文件或目录的原因，以代码或可观察行为支持结论并说明解决方向。

## Scope

- 仅排查并说明原因，不修改产品代码、不运行测试。

## Decisions

- 当前源码的单文件模式会删除非锚点、非 HTTP/HTTPS 链接的 href，并标记 aria-disabled；入口为 src/main.ts:1159，禁用逻辑为 src/main.ts:1197。
- 目录模式仅接管可识别文件格式的本地链接；普通目录链接被归为 other 并禁用（src/main.ts:1575；src/platform.ts:23）。
- file: 链接在目录模式被视为外部引用跳过；全局点击阻止默认导航却仅打开 HTTP/HTTPS，原生 open_external 也仅允许该协议（src/main.ts:1052、1647；src-tauri/src/main.rs:373）。
- 原生授权确实限制为明确选中的文件或目录；系统打开 Markdown 仅授予单文件权限，不能直接放开任意本地路径。
- 截图没有实际 href 和打开方式，尚不能断言其命中哪个分支；以上为当前源码证据，未复现已安装应用。

## Plan

1. 向用户解释单文件模式禁用本地跳转、目录模式不支持目录目标及 file: 链接的行为差异。
2. 临时使用目录导入后从文件树打开文档，以支持授权目录内的相对文件链接；不声称该方法能解决目录或 file: 链接。
3. 若后续授权修复，统一处理相对路径、绝对路径及 file: URL，并按文件或目录分流；缺少授权时明确提示或请求选择器授权，保留原生访问边界。
4. 若需精确确认截图个案，核对原始 Markdown 链接及应用打开方式；本轮未运行单元测试、构建或 GUI 复现。
