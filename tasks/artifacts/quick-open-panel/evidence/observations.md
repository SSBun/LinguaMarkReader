# 快捷打开核对记录

## 范围与版本

本任务修改 `src/quick-open.ts`、`src/main.ts` 的快捷打开接入区域和 `public/markdown.css` 的浮层样式；版本由同目录 `snapshot.json` 固定。

工作区已有其他任务改动，且实施期间另一任务增加了浏览前进／后退按钮。`integration.diff` 是实施前备份与当前文件的差异，包含这些非本任务的导航变化；导航状态、历史记录、前进后退按钮及其快捷键不是本任务交付，未撤销或改写。审查范围是快捷打开模块、其接入点和相关样式；完整文件散列用于发现审查期间漂移。

## 已执行核对

- `npm run check`：TypeScript 检查通过。
- `npm run build`：前端构建通过。
- `git diff --check`：通过。
- 在独立 Chrome headless 配置中加载真实构建产物，以 CDP 执行浏览器交互核对；不是项目测试套件。数据为虚构的 demo 路径，不修改用户的应用收藏。
- 打开浮层后，焦点为 combobox 输入框，默认第一项选中。
- 2 个收藏与 5 个最近项目中含 2 个重复项，实际显示 5 个项目，收藏项有星标，默认分为“收藏”“最近打开”。
- 搜索“技术文档 阅读器”仅显示同一个已收藏文件，保留星标；搜索不存在的内容显示空结果，移除 aria-activedescendant；空结果下 Enter 不打开文件、不关闭浮层。
- CDP 真实键盘 ArrowDown 移到第二项；Enter 调用原有 `read_file`，传入对应路径，正文更新且浮层关闭；焦点落在阅读容器。
- 清空后重开输入框为空并选中首项；ArrowUp 从首项循环至最后一项。模拟 isComposing 的 Enter 不打开项目。
- 点击目录项调用原有 `read_directory`，传入对应路径，关闭浮层并恢复阅读容器焦点。
- CDP Escape 关闭浮层，焦点恢复阅读容器。
- 25 个唯一项目时，列表 scrollHeight=1553、clientHeight=464；ArrowUp 到末项后 scrollTop=1089，末项在列表可视区域内；面板高度约 569px，只有列表滚动。
- 收藏与最近均为空时显示引导文字，浮层高度 188px，无固定大空白。
- 桌面截图：面板宽 680px、高约 478px。
- 390×650 视口：面板宽 358px，左侧 16px，页面 scrollWidth=390，无横向溢出，文件名和路径单行截断。
- 1100×320 矮视口：面板底边约 290px，结果区压缩为约 134px，头尾仍可见。
